# 711Project

This repo contains code for my FWE 711 class project. 

project_code.rmd runs the analysis. ProjectSlides.qmd recreates the slides used for the class presentation. getdata.R pulls the data from Google Earth Engine.

wisconsin_climate_data.csv contains values derived from OpenLandMap soil layers (Hengl 2018, doi:10.5281/zenodo.1476854; CC-BY-SA 4.0), so this file is shared under CC-BY-SA 4.0. Other columns derive from TerraClimate (CC0), NASA MODIS, and USGS SRTM.
